# 提示词助手 Chrome 插件

一个本地优先的个人提示词管理插件。支持分类、标签、示例图片、搜索、编辑、删除、一键复制，以及 JSON 覆盖导入和整库导出。

## 开发环境

1. 安装依赖：

   ```bash
   npm install
   ```

2. 构建扩展：

   ```bash
   npm run build
   ```

3. 打开 Chrome 的 `chrome://extensions`，启用开发者模式，选择“加载已解压的扩展程序”，加载 `dist` 目录。
4. 点击浏览器工具栏中的“提示词助手”图标，插件会在 Chrome 侧边栏打开。

## 首版范围

- 只支持 Chrome Manifest V3。
- 只做个人提示词管理，不做团队共享、公开模板库、网页右键采集或 AI 改写。
- 每条提示词必须有标题和正文，分类和标签可选。
- 默认分类包含“文本”“绘图”“视频”，也可以在新建/编辑提示词时输入新的分类名称来自定义新增。
- 提示词支持添加示例图片：可以上传图片文件，也可以在编辑弹窗中直接粘贴剪贴板图片。

## 数据迁移

插件不需要登录，数据保存在当前浏览器本地。换电脑时，在旧电脑点击“导出全部 JSON”，把导出的文件传到新电脑，再在新电脑插件里点击“导入覆盖 JSON”即可迁移提示词、分类、标签和图片。导入会覆盖当前库，适合你持续用最新备份替换旧数据。
